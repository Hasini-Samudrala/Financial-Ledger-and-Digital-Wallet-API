# Brain Query

## Purpose

Answer questions about the Financial Ledger & Digital Wallet API project using information stored in the team's Second Brain.

## Instructions

When asked a question:

1. Search the relevant folders in the Second Brain before answering.
    
2. Read the notes that are relevant to the question.
    
3. Prefer project-specific notes and approved decisions over general assumptions.
    
4. Use Obsidian links to identify connections between related notes.
    
5. Support technical explanations with references to the notes used.
    
6. Clearly distinguish documented facts from assumptions or suggestions.
    
7. If information is missing, say that it is not documented.
    
8. If two notes contain conflicting information, point out the conflict instead of choosing one silently.
    
9. Do not invent requirements, implementation details, or team decisions.
    
10. Keep answers simple, clear, and relevant to the question.
    

## Useful Locations

Search these folders when relevant:

- `projects/` — Project requirements and design documentation.
    
- `resources/` — Technical research and reference notes.
    
- `areas/` — Ongoing project knowledge.
    
- `inbox/` — Notes that have not yet been organised.

## Output Format

When answering, provide:

- **Answer:** A direct response to the question.
    
- **Supporting notes:** Links to the notes used.
    
- **Gaps or conflicts:** Any missing or contradictory information, if applicable.
    

## Quality Check

Before responding, verify that:

- The answer is supported by the Second Brain.
    
- Relevant notes are linked.
    
- No unsupported facts are presented as confirmed.
    
- Missing information is clearly identified.
