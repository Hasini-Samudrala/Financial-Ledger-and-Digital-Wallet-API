# AGENTS.md

## Project
Backend API for a digital wallet. It is a course project and never holds real money.

## Rules
- Never store money as float or double. Use whole paise (integers).
- Never edit or delete ledger entries. Fix mistakes with a reversal.
- Every balance change happens in one database transaction.
- Never commit passwords or keys.
- Never paste passwords or keys into an AI tool.
- Every change goes through a pull request, and a teammate reviews it.
- Every AI-written change must be checked by a human.
